# Cherry Spins — Telegram Mini App

Готовый стартовый проект Telegram Mini App в эстетике Cherry Spins: колесо призов, задания, рефералы и инвентарь. Это самостоятельная реализация по предоставленной видеозаписи, не исходный код оригинального сервиса.

## Возможности

- Адаптивный интерфейс для Telegram Web App и мобильного браузера.
- Колесо с серверным выбором приза и анимацией.
- Одна стартовая бесплатная прокрутка на нового пользователя.
- Задания с начислением дополнительных прокруток.
- Проверка подписки на канал через Telegram Bot API (если настроен `CHANNEL_ID`).
- Реферальные ссылки `?startapp=ref_<telegram_user_id>`.
- Инвентарь и журнал выигрышей.
- SQLite, проверка подписи Telegram `initData`.
- Минимальная статистика администратора.

## Требования

- Node.js 20+
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather)
- HTTPS-домен для production (Telegram Mini Apps требуют HTTPS)

## Локальный запуск

```bash
cp .env.example .env
npm install
npm run dev
```

Открой `http://localhost:3000`. В режиме разработки включён тестовый пользователь (`DEV_AUTH=true`). Это только для локальной разработки.

## Настройка Telegram

1. Создай бота в @BotFather и скопируй токен.
2. Укажи в `.env`:
   - `BOT_TOKEN` — токен бота.
   - `BOT_USERNAME` — username без `@`.
   - `WEBAPP_URL` — HTTPS-адрес приложения.
   - `ADMIN_TOKEN` — длинный случайный секрет.
3. Разверни приложение на HTTPS-хостинге.
4. В @BotFather настрой Menu Button / Mini App на URL приложения.
5. Для проверки подписки добавь бота администратором канала и укажи `CHANNEL_ID`.

`WEBAPP_URL` хранится для конфигурации деплоя; сам адрес Mini App задаётся через BotFather.

## Деплой

Подойдёт VPS или Node.js-хостинг с постоянным диском. Для SQLite нужен persistent volume: база создаётся в `data/game.sqlite`. Не используй эфемерную файловую систему, иначе данные могут пропасть после перезапуска.

Пример:
```bash
npm install
npm start
```

Установи переменные окружения из `.env.example`, выставь `NODE_ENV=production`, проксируй HTTPS через Nginx/Caddy и сохрани папку `data/` между релизами.

## Админ-статистика

```bash
curl -H "X-Admin-Token: $ADMIN_TOKEN" https://YOUR_DOMAIN/api/admin/stats
```

## Что нужно доделать перед публичным запуском

- Заменить тексты, канал и ссылки на свои.
- Настроить `CHANNEL_ID` и права бота для проверки подписки.
- Подключить Telegram Stars через `createInvoiceLink`, обработчики `pre_checkout_query` и `successful_payment`. Кнопка платного вращения сейчас является заглушкой и не списывает деньги.
- Настроить правила и юридические условия розыгрышей в соответствии с применимым законодательством.
- Добавить rate limiting, резервное копирование SQLite, мониторинг и защиту админ-панели.
- Проверить правила Telegram и требования к призам. Не обещать денежные выигрыши или вывод средств, если это не реализовано и не разрешено.

## Безопасность

- Сервер проверяет подпись Telegram `initData` и срок её действия.
- В production тестовая авторизация отключена.
- Не публикуй `.env`, токен бота или `ADMIN_TOKEN` в GitHub.
- Результат колеса выбирается сервером, а не браузером.
- Текущие награды — виртуальные предметы внутри приложения. Нет вывода денег, депозитов или обмена на реальные ценности.
